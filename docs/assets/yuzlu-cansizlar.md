# Yüzlü cansız görseller (tarama, 2026-10-12)

Kural (`docs/assets/style-guide.md` §1.7): cansız nesnelerde yüz yok. Eski stil bloğundaki "big expressive eyes where applicable" cümlesi yüzünden aşağıdaki görsellerde göz ve/veya ağız var. Sahip kararıyla bunlar topluca yenilenmez; yalnız **karışıklık yarattığında** (ör. canlı/cansız ayrımı, birbirine benzeyen seçenekler) yenilenir. Yenilenenler ilgili partide işaretlenir.

Tarama 1267 nesne görseli üzerinde temas sayfalarıyla yapıldı; "(?)" emin olunamayanlar.
